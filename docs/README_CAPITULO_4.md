# Documentación Capítulo 4 - Implementación

Este directorio contiene la documentación completa del Capítulo 4 de la tesis, incluyendo el documento principal y las capturas de pantalla organizadas por sprint.

## Estructura

```
docs/
  ├── CAPITULO_4_IMPLEMENTACION.md  (Documento principal)
  ├── GUIA_CAPTURAS_CAPITULO_4.md   (Guía para tomar capturas)
  └── capturas/
      ├── sprint1/                   (5 imágenes)
      ├── sprint2/                   (8 imágenes)
      ├── sprint3/                   (8 imágenes)
      ├── sprint4/                   (8 imágenes)
      └── sprint5/                   (5 imágenes)
```

## Uso

1. **Leer el documento principal**: Abre `CAPITULO_4_IMPLEMENTACION.md` para ver la estructura completa del capítulo.

2. **Seguir la guía de capturas**: Consulta `GUIA_CAPTURAS_CAPITULO_4.md` para saber qué capturas tomar y dónde encontrarlas.

3. **Organizar las imágenes**: Coloca cada captura en la carpeta correspondiente al sprint, usando los nombres sugeridos en la guía.

4. **Referenciar en el documento**: Las imágenes ya están referenciadas en el documento principal con el formato `[IMAGEN X.X]`.

## Formato de Nombres de Imágenes

Usa el siguiente formato para nombrar las imágenes:

```
sprint[X]_[descripcion].png
```

Ejemplos:
- `sprint1_advanced_ppi_converter.png`
- `sprint2_mapa_interactivo.png`
- `sprint3_dashboard_monitoreo.png`

## Notas Importantes

- Todas las imágenes deben estar en formato PNG para mejor calidad
- Resolución mínima recomendada: 1920x1080
- Oculta información sensible (IPs, tokens, contraseñas) antes de capturar
- Mantén consistencia en el estilo de las capturas

4. Revisar que todas las referencias `[IMAGEN X.X]` tengan su imagen correspondiente
